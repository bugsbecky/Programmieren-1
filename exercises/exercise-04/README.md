# Programmieren 1 | Übung 04 — Verzweigungen

Diese Übung vertieft **bedingte Anweisungen** (`if`, `else if`, `else`), **logische Verknüpfungen** und die Umsetzung von **Entscheidungsregeln** in Java.

Empfohlene Ordnerstruktur (analog zu Übung 01–03):

| Ordner    | Aufgabe | Vorschlag Dateiname              |
|-----------|---------|----------------------------------|
| `task-01` | 04_1    | z. B. `FolderOrderPrice.java`    |
| `task-02` | 04_2    | z. B. `TriangleProperties.java` |
| `task-03` | 04_3    | z. B. `DateValidation.java`      |

Kompilieren und ausführen (im jeweiligen Aufgabenordner):

```bash
javac Dateiname.java
java Dateiname
```

Die Aufgabenstellung je Teilaufgabe steht in der jeweiligen `task-*/README.md`.

---

## Kurzüberblick: Schwerpunkte (Übung 04)

| Thema              | Typische Verwendung in dieser Übung        |
|--------------------|--------------------------------------------|
| `if` / `else`      | Rabattstufen, Frachtfreigrenze, Eigenschaften |
| Bedingungen        | Dreiecksungleichung, Schaltjahr, Monatslänge |
| `double`           | Seitenlängen, Geldbeträge, Vergleiche mit Toleranz |
| Konsole            | `Scanner` oder vergleichbare Eingabe       |
| Testen             | Beispielwerte aus den Aufgabenstellungen   |

---

## Lernziele

Nach Bearbeitung der Übung sollten Sie

- mehrstufige Preis- und Rabattregeln mit Verzweigungen abbilden können,
- mehrere boolesche Eigenschaften unabhängig voneinander prüfen und ausgeben können,
- Kalenderregeln (Monatslänge, Schaltjahr) korrekt in Bedingungen übersetzen können,
- Programme mit den angegebenen Testfällen systematisch überprüfen können.
