Task 01_1 

a) Legen Sie eine Datei „Aufgabe01_1.java“ an und geben Sie darin das folgende Hello-WorldProgramm ein: public class Aufgabe01_1 { 
    public static void main(String[] args) { 
        System.out.println("Hello World"); 
    } 
} 

b) Führen Sie das Programm aus. Falls der Compiler Fehler meldet, korrigieren Sie den Quellcode, bis keine Fehlermeldung mehr erscheint.

c) Versuchen Sie durch Änderung des Quellcodes nacheinander mindestens 5 unterschiedliche Fehlermeldungen zu erzeugen und notieren Sie sich die jeweilige Fehlermeldung diese, bevor Sie den Fehler wieder rückgängig machen. Beispiele: 
• Weglassen eines Semikolons 
• Weglassen einer geschweiften Klammer 
• Änderung der Groß- und Kleinschreibung 
• Änderung des Klassennamens 
• Sonstige Tippfehler
